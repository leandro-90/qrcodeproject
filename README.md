# 📱 QR Code Component Project

Um projeto front-end simples e elegante que exibe um componente de cartão com QR Code responsivo, desenvolvido como parte de um desafio de codificação para praticar fundamentos de CSS e layout.

🔗 **Acesse o site:** [leandro-90.github.io/qrcodeproject](https://leandro-90.github.io/qrcodeproject/)

---

## 📌 Sobre o Projeto

O objetivo deste projeto é construir um componente de QR Code centralizado e responsivo, seguindo fielmente o design proposto. Ele serve para consolidar conceitos essenciais de estilização, alinhamento de elementos na tela e boas práticas de estruturação HTML.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do componente.
- **CSS3:** Estilização com Flexbox/Grid, sombras, bordas arredondadas e variáveis para gerenciamento de cores e fontes.

---

## 🎨 Funcionalidades e Destaques

- **Centralização Perfeita:** Alinhamento do cartão no centro da tela em qualquer resolução.
- **Design Responsivo:** Otimizado para telas móbiles e desktops.
- **Estilização Fiel:** Fidelidade às dimensões, tipografia e paleta de cores do layout de referência.
